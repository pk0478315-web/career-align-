# Student Opportunity AI — Browser Extension & 1-Click Autofill

A Chromium Manifest V3 browser extension for **Student Opportunity AI** that captures opportunities from any webpage and provides 1-click application form autofill.

---

## 🌟 Key Features

1. **1-Click Webpage Capture:** Extract title, organization, description, and source link from any opportunity page.
2. **Review Before Save:** Edit extracted titles and set application deadlines in the extension popup before committing.
3. **Application Form Autofill:** Automatically detects form fields (Name, Email, University, Major, Graduation Year, Skills, Portfolio) on application portals and pre-fills your profile data.
4. **Floating Action Bar:** Injects an optional floating widget on job and scholarship pages for instant 1-click filling.

---

## 🛠 How to Install in Chrome / Edge / Brave

1. Open **Google Chrome** or **Microsoft Edge**.
2. Navigate to `chrome://extensions` or `edge://extensions`.
3. Enable **Developer mode** in the top right corner.
4. Click **Load unpacked**.
5. Select the `extension/` folder inside your repository:
   ```text
   d:\programming\hack\extension
   ```
6. The extension **✨ Student Opportunity AI — Capture & Autofill** is now active!

---

## 🚀 How to Use

### 1. Capturing an Opportunity from any Website
- Visit any scholarship, internship, or hackathon page (e.g. `https://summerofcode.withgoogle.com`).
- Click the **Student Opps AI** extension icon in your browser toolbar.
- Click **"✨ Capture Opportunity from Tab"**.
- Review the extracted title & deadline, then click **"💾 Save to My Tracker"**.

### 2. 1-Click Form Autofill
- Open any application form (or click **"⚡ Autofill Application Form"** in the popup).
- Compatible inputs (Full Name, College Email, University, Major, Graduation Year, Skills) will be automatically detected and filled with highlighted green borders!
